# Metaphor options

Write three. Each is one line: the object, what it stands for, and how it moves.

Good options share these traits:

- One hero object that a reader can name in two words.
- The object maps to the post's idea, not to a generic "tech" look.
- It has a symmetry, so it can loop: a hexagon loops at 60 degrees, a square at 90, a 5-fold shape at 72.
- It reads as a silhouette at 390 px wide.

Avoid:

- Floating dashboards, fake app screens, or code on a monitor.
- A crowd of small objects with no hero.
- People, faces, hands, or mascots.
- Another company's product, logo or shape.

Example set for "qualify leads before you message them":

1. Signal funnel: hexagonal rings narrow to one lit core. Rings counter-spin 60 degrees.
2. Sorting gate: a square frame with bars that let one sphere through. Frame turns 90 degrees.
3. Lens stack: three glass discs that focus a beam onto one point. Discs turn 120 degrees.
