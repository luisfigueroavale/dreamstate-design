# scene.md

Every scene folder has one. Write it before `build.py`, and keep it true after every change.

| Field | What to write |
|---|---|
| Metaphor | One sentence: what the object stands for |
| Reading order | What the eye sees first, second, last |
| Hero object | The one object |
| Frame | Size name from `ds3d.SIZES` and the camera type |
| Loop | Angle, frame count, why it closes |
| Palette slots | Which part uses which slot |
| Built on | Blender version, engine, view transform |
| Words on the image | None, or where the HTML text goes |
| Outside assets | None, or the file, its license and the owner's yes |

See `3d/scenes/signal-funnel/scene.md`.
