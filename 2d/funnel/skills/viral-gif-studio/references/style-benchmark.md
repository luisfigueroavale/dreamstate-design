# Style benchmark: Michel Lieben / ColdIQ GIFs

The user shared four ColdIQ GIFs as the complexity bar (a fifth image arrived blank). The skill exists because the first Dreamstate drafts were too simple. This file records what the examples do so a new design can be checked against it.

These are observations about references, not permission to copy their palette, logos, claims or comment prompts. The house rules in [SKILL.md](../SKILL.md) win.

## The four reference GIFs

1. **"The 6-Step TAM Mapping Playbook"** (warm cream, terracotta). Hero: six isometric chessboard cubes stacked like a staircase, a chess piece on each (pawn, two rooks A/B, a king). Six numbered steps with leader lines (glowing node on the cube) alternating left and right. Side widgets: a 70% / 30% split card with an infinity bar and logo chips, tag pills (UK Tech, DACH Tech), A/B path cards, T1/P1 tier badges. Header: logo + pill "Unified API for GTM", two-tone title, subtitle. Footer: founder avatar, name, title, logo, URL.
2. **"Master AI for GTM"** (cream, terracotta, grain). Eight sections in a grid: principles chips, four playbook cards with mini illustrations and 5 to 6 numbered lines each, a dark Claude Code terminal (typing, checkmarks, "56 skills loaded"), a data-layer card with 70% / 30% bars and a logo row, a YouTube-channel avatar strip, a CTA pill ("Comment GTM to get the full package in DM"). Particles streaming into the title corner.
3. **"$7M LinkedIn Content OS"** (black starfield, orange glow). Hero: a ring of drifting particles around a glowing logo; eight numbered sections around it with leader lines to glowing nodes: content pillars with counts (188, 160, 118, 103, 47), formats, hub, channels, social engagers funnel icon, a slider that fills to "0K", a 15-skill command grid, "16,000+ posts" and "400+ designs" stat cards.
4. **"Define your ICP in 4 parts"** (cream). Four quadrants: a stack of translucent plates (8 company-fit layers), persona cards with tabs, a buyer-persona tree with checkmark chips, a radar with 1st/2nd/3rd party signal legend. Each quadrant has a numbered list of 8 to 9 short lines.

## What they share (the checklist)

| Lever | What to do |
|---|---|
| Hero object | One 3D or sculptural centrepiece specific to the topic. |
| Density | 4 to 8 numbered sections, each with a title, one line, and a gray detail note. |
| Simultaneous motion | 6 to 10 loops running together; something new to notice on every replay. |
| Concrete numbers | Percentages, counts, tiers and prices only when each has a source you can name. |
| Chips and logos | Rows of text chips, tag pills and badge labels (T1, P1, A, B). Third-party logos only when supplied. |
| Leader lines | Thin lines from each callout to a glowing node on the hero. Nodes pulse when their step is active. |
| Terminal or UI mock | A believable app window (typing, checkmarks, progress). |
| Frame | Supplied Dreamstate mark + pill, two-tone title, subtitle, footer with person + URL and a useful next step without engagement bait. |
| Palette | Use the filled brand files for palette and tokens. Soft shadows and rounded cards support the layout. |
| Format | 4:5 portrait, seamless loop, readable at phone width. |

## Why they spread
- **Saves**: a dense reference people want to keep.
- **Replay value**: many small motions reward a second look, boosting dwell time.
- **Recognisable frame**: same header/footer every time builds brand recall before the text is read.
- **Useful next step**: tell readers how to use the reference. Do not copy the reference comment triggers or add engagement bait.

## v1 vs v2 (lesson from the first Dreamstate drafts)
v1 were blue diagrams: a title, 8 boxes joined by lines with a few pulses, a 3-step playbook, a CTA. Flat, one motion type, no hero object, no UI mocks, no numbers beyond the copy. v2 added: an isometric hero with 16 bots, a typing terminal, an approval queue with a clicking cursor, orbiting avatars with idea particles, a scrolling feed, a particle brain with waves, cost bars that fill, checklists. When reviewing a draft, ask: "Could this be described in one sentence as a diagram?" If yes, it is still v1.
