# 3D palette

Blank form. The filled copy is `brand.local/3d.json`, which git ignores. Scenes read only these five slots. A scene never names a color of its own.

| Slot | Used for | Value |
|---|---|---|
| `background` | World color and floor | |
| `hero` | The main object's material | |
| `accent` | Secondary parts, glass tint, fill light | |
| `glow` | Emission, the one bright point | |
| `rim` | Rim light color | |

Take each value from `brand.local/style.md`. If style.md does not name a color for a slot, leave it blank and ask the owner. Do not invent one.

`brand.local/3d.json` looks like this, with the owner's own hex values:

```json
{
  "background": "#RRGGBB",
  "hero": "#RRGGBB",
  "accent": "#RRGGBB",
  "glow": "#RRGGBB",
  "rim": "#RRGGBB"
}
```

A scene run with `--palette brand` stops when any slot is missing or is not a hex value.

Tips that hold for most palettes:

- A dark `background` makes glass and metal read. A light one needs a stronger `rim`.
- Keep `glow` for one thing per frame.
- `hero` and `background` need clear contrast at 390 px wide.
